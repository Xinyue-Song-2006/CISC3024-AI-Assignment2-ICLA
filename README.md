It is separate from the account's other projects.

## Method and scope

This is an independent small-scale implementation of the central procedure from
**Maksim Zhdanov, Stanislav Dereka, Sergey Kolesnikov. Identity Curvature Laplace
Approximation for Improved Out-of-Distribution Detection. WACV 2025, pp. 7019–7028.**

- [Official paper record](https://openaccess.thecvf.com/content/WACV2025/html/Zhdanov_Identity_Curvature_Laplace_Approximation_for_Improved_Out-of-Distribution_Detection_WACV_2025_paper.html)
- [Full preprint, revised 2024](https://arxiv.org/html/2312.10464v2)
- [Authors' implementation](https://github.com/maxnygma/icla)
- [Digits dataset documentation](https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_digits.html)

This repository does not claim to reproduce the paper's CIFAR or ImageNet scores.
It implements an MLP final-layer Bayesian approximation in NumPy and SciPy.
The upstream source was inspected, not copied.

Methods share one fitted model for every task/seed:

1. **MAP**: deterministic softmax baseline.
2. **LLLA-EF**: diagonal empirical Fisher covariance `(h + lambda)^(-1)`.
3. **ICLA-EB**: fit the same empirical-Bayes precision, then discard curvature and
   use covariance `I / lambda`.
4. **ICLA-Val**: identity covariance with precision chosen using only clean
   validation NLL; an additional tuning variant, not the original evidence procedure.

Prediction uses the approximate multiclass probit link
`softmax(logits / sqrt(1 + pi * logit_variance / 8))`.
ICLA applies a common positive divisor per image and preserves the argmax class.
The empirical-Bayes mode is frozen: the MLP is not retrained for each precision.
The MLP's original L2 penalty excludes biases, while the post-hoc Gaussian includes
the final bias. This is an approximation, not an exact consistent-prior posterior.

## Reproduce

Tested with Python 3.13.7 on Windows using CPU computation and one BLAS thread.
Use a fresh virtual environment and the pinned packages:

```shell
python -m pip install -r requirements.txt
python experiment.py --output results
python verify.py
python make_figures.py
```

The dataset ships with scikit-learn; no separate download, GPU or credential is
required. The standard run overwrites the generated `results/` files. Run in a
fresh checkout if you want to preserve the committed reference results.
`verify.py` and `make_figures.py` use the `results/` folder beside the scripts.

## Protocol fixed before final evaluation

- Seeds: 0, 1, 2, 3, 4; split and initialization vary together.
- Pixels divided by 16; no fitted preprocessing.
- Ten-class recognition: 1,077 train / 360 validation / 360 test samples.
- Additional corruption: Gaussian pixel noise with sigma 0.25, clipped to [0, 1];
  noise RNG seed 10,000 + experiment seed.
- Separate open-set models: digits 0–4 only; 540 train / 180 validation / 181 ID test;
  all 896 images of digits 5–9 are OOD evaluation data.
- 64–64–C ReLU MLP; L-BFGS, alpha 1.0, tolerance 1e-7, max_iter 3,000,
  max_fun 50,000. No augmentation or early stopping.
- Evidence optimization: minimize the frozen-mode negative log evidence in
  log(lambda), bounded to [-12, 12].
- Validation tuning: 81 log-spaced values between 0.01 and 1,000,000.
- No test or OOD labels are used in training or precision selection.
- ECE: 10 equal-width confidence bins. Multiclass Brier sums over classes.
- OOD is positive; its score is `1 - max(probabilities)`.
- Aggregates are mean +/- sample SD over five seeds, not confidence intervals.

## Recorded results

| Task | Method | Accuracy (%) | NLL | ECE | OOD AUROC |
|---|---|---:|---:|---:|---:|
| Clean 10-class | MAP | 97.61 | 0.0920 | 0.0276 | - |
| Clean 10-class | LLLA-EF | 97.33 | 0.7817 | 0.4972 | - |
| Clean 10-class | ICLA-EB | 97.61 | 1.0361 | 0.6101 | - |
| Clean 10-class | ICLA-Val | 97.61 | 0.0920 | 0.0276 | - |
| Noisy 10-class | MAP | 90.89 | 0.2969 | 0.0297 | - |
| Noisy 10-class | ICLA-EB | 90.89 | 1.2206 | 0.5944 | - |
| Open-set, known 0–4 | MAP | 99.45 | 0.0306 | 0.0180 | 0.9549 |
| Open-set, known 0–4 | LLLA-EF | 99.45 | 0.4833 | 0.3698 | 0.9618 |
| Open-set, known 0–4 | ICLA-EB | 99.45 | 0.5516 | 0.4121 | 0.9615 |
| Open-set, known 0–4 | ICLA-Val | 99.45 | 0.0306 | 0.0180 | 0.9549 |

Full per-seed metrics and standard deviations are in `results/metrics.csv` and
`results/summary.csv`. ICLA-EB is substantially underconfident on this small
dataset. It provides a small OOD ranking improvement over MAP, while LLLA-EF is
slightly higher still. Every validation-tuned run selects the upper precision
boundary (1e6), effectively recovering MAP. This boundary solution is not evidence
of a useful finite-uncertainty optimum. Negative results are intentionally retained.

## Files and audit trail

- `experiment.py`: complete training and evaluation implementation.
- `verify.py`: finite-difference Fisher check, evidence stationarity check,
  Gaussian variance sanity check, independent metric and aggregate calculations,
  split isolation and code-hash verification.
- `make_figures.py`: regenerate figures directly from saved arrays.
- `results/predictions.npz`: raw model probabilities for every task/seed/condition.
- `results/model_*.npz`: trained network parameters and post-hoc parameters.
- `results/splits.json`: exact dataset indices.
- `results/validation_grid.csv`: all tuning candidates and validation scores.
- `results/metadata.json`: versions, numerical setup, warnings, measured durations,
  code/data SHA-256 hashes.
- `results/verification.json`: final verification outcome.
- `figures/`: PNG and editable SVG figures.
- `AI_WORKFLOW.md`: actual AI workflow and methodological decisions.

The submitted PDF is delivered separately and is not needed to execute the code.
No personal academic identifier is needed in this public source repository.
